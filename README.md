# Sajjad Ansari | Portfolio

This is the source code for my personal portfolio, built with HTML, CSS, and Vanilla JavaScript.

## Features
- **Modern UI**: Clean, minimalistic, and high-performance design.
- **Responsive**: Fully responsive across mobile, tablet, and desktop devices.
- **Dynamic Projects**: Links to featured applications, open-source codebases, and case studies.

## Tech Stack
- HTML5
- CSS3 (Vanilla, CSS Variables for theming)
- JavaScript (Vanilla, smooth scrolling, intersection observers)

## Local Development
To run this locally, you can use any standard static file server.
For example, using Python:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.
